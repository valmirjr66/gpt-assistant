## Steps to start the API:

1. Add a .env configuration file with following entries:

-   API_PORT
-   OPENAI_API_KEY
-   CLOUD_API_ADDRESS
-   NOTION_TOKEN
-   DATABASE_URL (e.g.: "mongodb+srv://<user>:<password>@projetos.splss.mongodb.net/projetos?retryWrites=true&w=majority&appName=projetos")

2. Run `npm i`
3. Run `npm start`
